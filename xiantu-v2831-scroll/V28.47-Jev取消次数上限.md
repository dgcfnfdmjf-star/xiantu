## 六处入口与行为

| 入口 | 判断内容 | 执行方式 |
| --- | --- | --- |
| 宗门 → 弟子事务 → Jev 推荐派遣 | 比较最多前5名空闲弟子、3种任务；选本人可执行的最高难度，结合专长、天数与实际奖励 | 先展示建议，选择后仍走原有派遣确认；无自动花费 |
| 姻缘亭 → 已解锁人物 → Jev 人物回应 | 根据好感、已完成事件和道侣状态选克制、倾听或温和回应 | 确认后进行一次交谈；不增加好感收益、不绕过剧情门槛；对话文本来自游戏预设 |
| 正魔大战 → 当前战役 → Jev 战术参议 | 根据强攻/固守/分兵敌情选反击/迂回/集中战术 | 玩家选定后才修改战术；不自动宣战或发动战斗 |
| 地图顶部 ☯ Jev / 自动战斗策略 → Jev 选招 | 在已携带、武器匹配且灵力足够的技能中选招，尊重保命及保留灵力设置 | 默认关闭；开启后首次出招、气血/灵力区间或首领阶段变化时判断，不设单场次数上限；超时或低置信度用本地策略 |
| 万宗秘境 → Jev 秘境探索 | 在原有40%事件分支中选择达到境界要求的事件 | 仍消耗30个游戏日；其余分支照常遇敌，奖励与资格沿用原规则；取消不结算 |
| 宗门大殿 → Jev 宗门经营参议 | 根据灵石、贡献、弟子事务、战役状态选择任务/弟子/藏经阁/军务 | 确认后进入对应实际功能，招募或兑换继续按原界面操作 |

这些功能选择现有合法选项，不生成自由文本剧情，不新增伤病、忠诚等尚不存在的弟子属性。天劫、新手引路和大比不启用主角 Jev 自动选招。
在战斗中打开 Jev 设置会暂停自动出招，关闭设置后点击“继续”。已发出的招式照常完成。
