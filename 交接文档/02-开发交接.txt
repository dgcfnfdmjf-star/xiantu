一、目录与架构
xiantu-v2831-scroll/ 是实际部署的静态目录，不需要 npm 构建。
index.html 为入口；game-v2762.html 为分段加载入口，包含有顺序的 39 个运行脚本。
xiantu-v2762-core.js 为主逻辑，xiantu-v2762.css 为基础样式。
xiantu-v2868-sect-life.js 为最近宗门扩展；其他版本命名的脚本仍在运行，不可按文件名判断过期后删除。
intro-v2860.mp4 及图片、视频资源需完整保留。
QA/ 中有模拟 DOM 测试与历史测试，不能视为真实浏览器测试。
tencent-jev-function/ 是后端源代码，独立云函数 ZIP 为 xiantu-jev-cloud-function-v2850.zip；前端版本更新不代表后端版本一定更新。

三、改动注意
保留模块加载顺序和构建就绪检查。当前版本标记为 28.68/2868；变更时同步 HTML expectedBuild、CSS --xiantu-build、脚本 __xiantuBuildFilesV2814 标记、资源查询参数和相关界面版本文字。不要仅改入口版本号。
主存档使用 localStorage，关键键为 xiantu_save 与 xiantu_save_backup。改字段应提供默认值和兼容处理，不能清空玩家存档。
Jev 用于受约束的行动/建议选择；现有编写剧情不能直接宣称是无限自由模型对话。
用户偏好手机友好、界面自然直观；不要在产品界面塞技术说明或占位文字。

四、验证边界
历史交付使用 Node 语法检查与模拟 DOM 测试，未完成真机画面、触控和内存验证。也没有通过本次打包执行在线部署或付费 API 调用。
在解压根目录可运行：
XIANTU_TEST_ROOT=./xiantu-v2831-scroll node xiantu-v2831-scroll/QA/v2868-test.cjs
