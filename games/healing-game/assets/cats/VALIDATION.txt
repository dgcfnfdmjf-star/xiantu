=====================================

基线：main 8812ff565b29a0f57bdcb80698f6c8b950ca3965 的已审静态坐姿。
历史 walk-candidate/ 是用户看过的未通过版本；最终验收材料在 walk-preview/。
不修改玩法、移动速度、奖励、存档或其他章节；版本仍为 V9.5。

修复与保留
----------
后腿：20 关节骨骼配合四个周期修形，保持髋/膝/跗关节与小腿体积，避免候选
后腿被压扁或拉成薄片。四足交替踏步，身体轻微起伏，头尾轻摆。
脚掌：补齐圆润内侧接触面，用同一毛色函数的 256px JPEG 着色，移除平面
封口大色块。原 1024px 毛色 JPEG 字节完全保留，没有重烘焙或再压缩原贴图。
坐姿：新增接触面收在原身体内，停止 Walk 立即恢复坐姿，避免暴露切口。
原 5,254 个外侧毛皮三角面、眼睛和眼睛高光保留；位置/UV/法线仅有界量化。
小鼻子、胡须和细线略作简化，给新增腿部和隐藏接触面留出面数。
每只 7,430 三角面，比原 6,886 增加 544（7.9%），仍在约 7,000 面量级。
Y 向上，+Z 朝前，轴心仍在地面；原坐姿比例、颜色、卷尾不变。

游戏侧接线
----------
每只实例独有骨骼与 AnimationMixer，同毛色共享几何体、材质和纹理。
移动时播放 1.6 秒 Walk；步幅 0.40 模型单位，按原 stepTo 的速度、归一化比例
和猫尺寸计算 timeScale。漫游 .55 / 引诱 1.1 / 躲藏 .75 / 集合 1.0 均不改。
停止或进入 hop/hug/sleep/play 时停播并恢复原坐姿，只保留原呼吸/整体反馈。
常量接触面预计算为坐姿/Walk 两份共享表面；坐姿不用蒙皮着色器，隐藏内侧
和小腿补面（6 次绘制）；Walk 使用完整骨骼、周期修形和 8 次绘制。
完整 Walk 外沿供原有避让使用；加载失败、静态旧文件或损坏骨骼均回退程序猫。
离开章节停播；晚到加载不挂场景，删除猫只释放私有骨骼资源。

浏览器视觉验收
--------------
实际加载最终压缩 GLB，检查正面、侧面、背面、坐姿和完整循环；另在游戏中
检查桌面 1200×900 DPR1 与手机竖屏 390×844 DPR2，实际点击移动猫的头部。
orange 橘猫：通过。已检查后腿体积、脚掌封口和坐姿接缝；所查角度未见原问题。
calico 三花：通过。花斑保留，内侧毛色连续，四足交替与坐姿恢复正常。
black 小煤球：通过。深色毛发与黄眼保留，后腿/脚掌无明显断口或色块。
tabby 狸花：通过。原条纹与绿眼保留，尾巴和后脚纹理无新增碎斑。
逐猫在桌面和手机环境各采样 96 个循环相位，最低点约 0.000740 模型单位，
外沿半径约 0.705032（导出保守值 0.710）；循环接点差约 0.0000012。
返回坐姿与初始坐姿几何差不超过 0.000001。原外侧 UV 冲突和退化均为 0。
极近距离仍可见轻量网格关节的少量折线；这不是高面数或照片级模型。

Fast 4G 与帧耗时
----------------
Chromium 151.0.7922.173，Linux / ANGLE Vulkan SwiftShader 软件渲染。
390×844 CSS 像素、DPR2、触屏模拟；Fast 4G 下行 9 Mbps、上行 1.5 Mbps、
延迟 60 ms。每版三次、交替顺序、全新 context、HTTP 缓存禁用、no-store。
计时为进入第二关到四种猫及装饰橘猫全部挂入场景，不包含初始 HTML 下载；
OS/进程/GPU 缓存可能预热，包含解析、图片解码和调度，不是单独 GPU 上传。

就绪时间中位数 [最小–最大]，ms：
  main 静态版：1,944.0 [1,785.4–1,975.2]
  Walk 新版：  2,234.4 [2,139.3–2,332.9]
增加 290.4 ms（14.9%）；文件体积略降，但动画解析/就绪有这部分额外成本。
就绪后再等两帧的中位检查点：2,438.1 → 2,674.5 ms（包含渲染和调度）。

固定同六只猫的位置、毛色与尺寸，1.8 秒预热后采样 5 秒，其他岛景照常运动。
用于隔离显示开销，移动展示状态保持原地，以免不同站位影响比较。
帧间隔中位数 / p95，ms：
  main 坐姿：116.1 / 142.3，n=41；新版坐姿：114.3 / 143.3，n=42。
  main 移动展示（仍为静态猫）：121.5 / 144.5，n=40。
  新版 Walk：128.5 / 161.2，n=37；中位增加 7.0 ms。
以上是云端软件渲染相对开销，不能宣称实体手机稳定 30/60 FPS。
