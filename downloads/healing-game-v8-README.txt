暮色浮岛 V8.0 · 晨风铃谷（2026-11-05）

第四关玩法
1. 完成第三关「星灯夜航」的三座灯，第四关自动解锁。
2. 在第三关结局点击「第四关：晨风铃谷」，或在旅程手账选择第四关。
3. 点击「听一遍」，跟随声音与编号提示奏回旋律。可以点场景中的风铃，也可以点底部编号；「查看乐谱」随时提供帮助。
4. 三段旋律全部完成即可通关，没有限时。错音只需重奏当前段，已经完成的乐章与收藏保留。
5. 六枚新音符加入统一图鉴，总收藏41种。每种首次收藏+5成长，首次通关+20；重玩和自由合奏不会重复发奖。

保存与兼容
兼容 V5/V6/V7；旧通关玩家直接解锁第四关。每个正确音自动保存，可刷新、切关后继续。
使用相同域名和浏览器才能继续原本地存档。保存失败时页面会提醒，恢复浏览器可用存储后自动重试。
保留原有音乐/音效开关、夜航玩法和三个关卡；第四关新增独立配乐、晨光场景及可跳过的通关演出。
