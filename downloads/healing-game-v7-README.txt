暮色浮岛 V7.0 · 星灯夜航（2026-11-05）

本次整合
- 独立的「星灯夜曲」，六种星萤各有拾取音色。
- 轻点/划过拾光，光点飞向灯座；灯座编号、蓄光刻度和灯心偏好提示。
- 三灯点亮后光束相连、夜色加深，纸船沿灯座巡航；可跳过演出。
- 每次拾光为天空增添星星（最多60颗），手账增加夜航记事和收集计数。
- 保留 V6 的三关、35种收藏、五级成长及装饰。旧进度自动继承，不重复发成长奖励。
- 改善触控误点、后台暂停、减少动态效果设置和保存失败恢复。

5. 不要覆盖根 index.html、xiantu-v2831-scroll/index.html 或仙途 game-v2762.html；不要上传 ZIP 作为网页。
