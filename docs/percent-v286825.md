# V28.68.25 百分比洗练

## 规则

新洗练仍随机两种不同属性，费用仍是每档200/400/600灵石。原品质档级修复保留，新范围为：

|档级|攻击/防御|气血/灵力上限|
|---|---|---|
|1|1%–3%|2%–5%|
|2|2%–6%|4%–10%|
|3|3%–9%|6%–15%|

百分比作用于角色对应属性，同属性的多件洗练加成与原装备对应百分比相加，不逐件相乘；不再乘品质倍率或强化倍数。角色原有的境界、装备固定值、旧固定洗练、套装固定值等继续计入基础，再走原来的百分比计算和取整、地区状态。护甲状态与原有公式顺序保持不变。提高最大气血/灵力不即时恢复当前值。

无其他加成时，1000气血基础搭配10%词条为1100；再加另一件5%为1150，不是1155。强化可以提高原装备固定属性，从而改变角色基数，但不能把10%词条本身强化成15%。

低境界时，新百分比不一定强于旧固定值，可在新旧对比后保留旧词条。没有自动补差或强制换洗。

## 存档与面板

- 新词条明确保存 `unit:'percent'`；没有该标记的旧词条继续按固定值处理，旧待选结果也保留原单位。
- 登记装备时从原始装备重新计算，百分比进入 `modsV2790` 同类加成，固定属性不重复加入百分比数字。
- 装备栏、背包、工坊标注洗练百分比；装备对比补充洗练百分点变化，评分沿用已有百分比加分逻辑（评分仍为启发式，不代表实战胜率）。
- 洗练对比表改为「试穿后角色面板对比」：同一件装备、同一槽位分别计算原词条和待选词条的攻击、防御、最大气血、最大灵力，避免直接比较+90与+9%。
- 身上装备使用原槽位；背包装备使用首个空槽，否则第一个可用槽。预览不实际穿戴、不改存档，临时装备定义、装备引用及套装状态会在正常或异常退出时恢复。
- 仍需手动保留或替换，待选阻挡重洗，旧的过期按钮、换角色和战斗保护保持。

## Jev

配套云函数支持v1/v2固定词条协议及v3试穿面板协议。v3只发送四项新旧预估面板、档级和偏好，不发送姓名、存档、装备清单或自由提示词。服务器严格限制字段类型、整数范围（0到10亿）和档级，原鉴权、域名白名单和限流保持。v3允许四项面板均非零，提示模型比较相对变化，不再次乘品质或百分比。

仅本地洗练和本地比较不依赖Jev。使用云端建议请先更新配套云函数，再覆盖网页；旧云函数可能拒绝v3，此时本地结果与词条不变。入口仍为index.main，原环境变量保留。未部署腾讯云，未发起付费Jev调用。
