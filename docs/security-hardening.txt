仙途 V28.68.70：存档与 Jev 接口安全加固

本批参考两份说明、两份补丁及其测试，逐项对照当前代码实现；没有直接应用以另一套 50 脚本布局为基线的补丁。沿用 40 脚本、SAVE_VERSION=12 和现有地图优化。

已复现并修复
1. 人物面板改道号原先接受 O'Reilly，随后存档校验拒绝。现在先校验完整输入（截断之前），不合法时保留原道号和输入。合法道号最多 8 个 Unicode 码点；写入失败回滚道号并保留待重试输入。可正常清除道号。
2. 存档自由文本校验补上斜杠等分隔符后的事件属性，如 x/onpointerenter=。正常纪事中的英文引号、反斜杠等保留原文，不执行附件建议的全量字符替换。原有大小、深度、标识和原型键校验继续有效。
3. 游戏、index、game、托管检测和 Jev 检测五个入口增加 CSP 与 no-referrer。允许本地脚本/资源、data/blob 图片与媒体，以及当前 Jev 网关；禁止 eval、外域脚本、外域图片、iframe、object、base 与表单导航。游戏仍需 unsafe-inline 兼容原有事件处理器，这不是对所有注入风险的彻底修复。
4. Jev 的成功、缓存、预检和错误响应统一包含 nosniff、no-referrer、禁止嵌入的 CSP/X-Frame-Options 与 HSTS，不改变原 CORS 白名单。
5. 可选 JEV_SESSION_SECRET 独立签名密钥：未设置时兼容原 API 密钥签名；显式设置必须至少 32 个去除首尾空白后的字符、原字符串不超过 4096 字符。配置为空或过短会让公共票据请求返回 503 session_config，不会静默退回旧密钥，拥有者口令模式仍可用。使用随机生成的密钥；启用或轮换后旧票据失效，客户端需重新连接。
6. 拒绝日志仅输出 evt、status 和固定错误码，不输出 IP、请求内容、令牌、密钥或供应商异常。每个实例每类错误每 60 秒最多一条，JEV_LOG=off 可关闭；这是采样诊断，不是逐请求计费或审计日志。

保留与未接入
- 当前已有共享 Redis 原子限流、小时/每日预算、超时、输入白名单与响应校验；保留默认付费 60 次/小时、300 次/24小时，不提高到附件的 120/1000。
- 本轮保留既有公开试玩与 JEV_REQUIRE_SHARED_LIMITER 配置语义。多实例部署应使用共享限流；内存计数不能成为跨实例预算上限。没有在更新代码时强制关闭现有试玩。
- 未加入 Turnstile：附件中 4 秒请求超时与最长 15 秒校验冲突，且脚本加载/控件取消尚未覆盖完整生命周期；当前也未配置人机校验站点。
- 元婴起闭关 50%～70% 上限与比例奖励属于另一项玩法改动，本轮未启用，闭关、战斗收益和突破规则保持现状。
- 不添加不会在腾讯 CloudBase 自动生效的 _headers 文件。静态 HTML 的 meta CSP 不支持 frame-ancestors/HSTS/nosniff；如需防游戏页面被嵌入，须在托管层设置响应头。

更新注意
游戏包与 Jev 云函数包分别更新。更新静态包可获得道号、存档及页面策略修复；要获得接口响应头、日志与独立密钥支持，需要同时更新原 Jev 云函数代码，入口仍为 index.main，保留原环境变量。新变量不强制配置，勿把密钥写进网页或仓库。
更换 Jev 网关时，同步修改 xiantu-v2842-jev-forge.js 的 endpoint 与五个入口页 CSP 的 connect-src。新增回归会检查 CSP 包含配置的网关来源。
只生成和上传部署包，本轮未合并 main、未部署腾讯云。
