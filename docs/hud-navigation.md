# HUD 入口分组

2026-10-14，基于 main `29f3ac9`。本次交付包含界面整理、导航回归与验收记录；腾讯云部署另行进行。不改战斗规则、存档字段与 Jev 服务。

## 入口位置

| 位置 | 入口 |
| --- | --- |
| 主屏顶栏 | 任务、角色、物品；触屏设备保留快捷菜单开关 |
| 小地图下方「探索」 | 山河图、探索手册、建筑名称开关 |
| 角色 → 修行与设置 | 修行指引、初入仙途下一步、摇杆/点触移动、Jev 中心、版本信息、宗门待办 |
| 角色名称旁 | 触屏设备的状态栏展开/收起开关 |

角色的设置分组默认收起，不挤占人物与修炼内容。探索手册即使正在显示目标方向，也保留“探索手册”名称。宗门待办沿用原来的解锁条件、禁用状态与数量刷新；新手进度、地图标记和移动模式沿用原存档逻辑。原手机快捷菜单仍保留存档、装备、声音等入口。

390px 非触屏模拟的顶栏从 12 个入口、754px 内容宽度，收敛为 3 个入口；触屏浏览器模式为 3 个入口加快捷菜单。手机 HUD 和小地图左右分开，地区名称移到摇杆上方。快捷菜单调整到开关下方，并允许在矮屏内滚动。

探索抽屉使用原生 details/summary：支持键盘展开、Escape 收起并返回开关、点击外部或切换焦点关闭，窗口尺寸改变和切到后台也关闭。选择入口后抽屉收起；从角色打开其他面板时先关闭角色。分组内键盘操作不会传到地图移动处理器。

各功能直接在固定容器内创建入口，保持原有事件与状态刷新，没有增加全局 MutationObserver、轮询或脚本加载项。40 个脚本加载顺序与版本标记保持不变。
