# V28.68.10 战斗动作节奏

沿用 V28.68.9 的剑修、野狼透明动作图集及水墨背景，没有新增运行素材。本轮只调整展示层，原战斗函数继续负责伤害、技能消耗、回合和存档。

近战采用蓄势、快速出手、停留和缓慢收招四段，狼扑增加离地高度和收缩的地面阴影。治疗、雷法及其他元素技能原地施放；战斗入口临时传递技能信息，让攻击开始时就选择正确的近战或施法表现。技能随后触发的特效丰富当前动作，不重新开始攻击。反击排队播放，积压队列最多四个动作，避免长期播放旧回合。

受击改为柔和淡入及短暂退让，治疗不触发受击退让。命中有短促散射线；数字带描边并分行偏移，区分暴击、灵宠伤害和治疗。气血文字加大，招式提示增加底色。演示页重置会同时清除动作队列、受击和浮字。
