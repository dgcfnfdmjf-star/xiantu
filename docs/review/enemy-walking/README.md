# 地图敌人走路验证

基于 main `86ea538`，与 NPC 自然走动 PR #79 独立。版本仍为 V28.68.123，由用户安排候选版本号、合并和部署。根 `index.html`、`healing-game/`、NPC 绘制/走动和存档结构没有修改。

## 实现与帧来源

实际地图入口是 `xiantu-v2853-monster-art.js` 对 `drawInkEnemyV2833` 的覆盖。检查了旧 `ink-beasts-v2833.webp`、`ink-enemies-v2833.webp`、`monster-map-v2853.webp` 和小兽图：各格是不同身份，**没有备用走路帧**。因此新增 20 张透明水墨 WebP，每张 512×480，128×160 单格、前/侧/背三排，每排站立 0 帧和动作 1/2/3 帧。总计 240 格，1,853,288 字节（约 1.77 MiB）。[全部图集预览](atlas-overview.webp)。

每只怪的 WeakMap 状态只在内存中，按实际位移推进 `phase += distance * profile.phase`，循环 `[1,2,3,2]`；停下和冷却时使用 0 帧。位移的 `atan2` 决定八向，切换前/侧/背排及镜像。起伏随同一步相推进，原脚下阴影、血条和精英 ★ 保持原绘制。精英使用同一家族步态与已有尺寸。

所有家族正常画质均使用新画的多帧图，没有把其他怪物的旧格冒充动作帧。加载失败或 `PERF_CONFIG.mobile && PERF_CONFIG.lowEnd` 时，使用原身份贴图做距离驱动的起伏、左右摆动和轻微形变；不会原地踏步。蛇、龙、鬼和飞行家族使用符合身体结构的蜿蜒、衣摆或振翅动作。

参数集中在 `MONSTER_GAITS_V1`。独立种子控制方向和停留；警戒只改变朝向，脚不动。到达障碍或家点范围后重新选择可走方向。原碰撞解算、POI 避让仍保留，移除了树碰撞的 3% 放行；完整位移（包括 POI 推离）再做线段检测，避免跨过薄碰撞体。新全景地图上的现有野怪共用这套敌人入口，服务点和 NPC 不参与。

60px 接触判断、引导期/战区保护、8 秒战后冷却数值、重生上限与 0.42 秒分批补充均保持原代码。冷却期间只暂停怪物步行，不改时钟、遭遇条件或敌人战斗数据。没有新 timer 或 RAF；只复用世界更新循环。图片按需加载，缓存最多 8 张（解码 RGBA 约 7.5 MiB），页隐藏/离开时释放；不为每只怪每帧创建 canvas 或步态对象。

## 浏览器证据

2026-11-13，云端 Linux、系统 Chromium 151、headless、DPR 1。使用合成角色并阻断全部外部请求，没有读取真实存档或调用付费 Jev。观察脚本只在测试页放置敌人和采样；移动、取帧、碰撞、战斗使用实际游戏函数。原始诊断位于忽略目录 `output/playwright/enemy-walking/`，选取的截图和 [完整采样](observations.json) 随本 PR 保存。

- [狼/鬼/山贼站立及动作帧对比](gaits.webp)：真实游戏截图裁切放大 2 倍，无重绘。三只怪从站立开始自然活动，55 次采样中狼走动/停留为 28/27 次，鬼 29/26 次，山贼 23/32 次，停走转换分别为 3/4/4 次。[起始](standing.webp)、[走动中](walking.webp)、[稍后位置](later.webp)可对照地图。
- [实际障碍前](obstacle-before.webp)、[靠近障碍](obstacle-near.webp)、[离开障碍](obstacle-after.webp)：向西域既有 `wild_3` 碰撞体行走，35 次采样最小净距离约 1.15px，没有进入碰撞体。
- 八张地图加载实际全景及碰撞体，调用原生成函数，再将测试角色放入安全区，逐张推进 120 秒模拟时间。南/东/北/西及四张势力图分别有 2/4/2/6/3/3/5/3 只怪，每步检查区域边界、全部碰撞体、POI 和安全区，违规数均为 0；所有地图均观察到走动和停留。此项是浏览器中的加速物理验证，不是帧率测试。
- [59px 实际接触战斗](contact-59px.webp)：60px 时 exploring，59px 时进入 combat，目标为野狼。[战后冷却](cooldown.webp)：实际战斗结束后，观察 4.5 秒，冷却从约 7.81 秒降至 3.26 秒，怪物始终停在 `(950,830)`，步相保持 0，没有再次贴近/触发战斗。专项逻辑测试另外验证原始释放值为 8 秒。
- 重新加载 V28.68.123 合成旧档后可正常入图，无运行时脚本错误。步态状态没有写入 player 或敌人数据；专项测试验证更换/规范化 player 后 WeakMap 状态从当前位置、步相 0 重新建立。
- 角色面板开关三次：面板内地图绘制数为 0；关闭后每 0.5 秒为 31/30/30 帧，重复 resume 未增加循环，canvas 始终 1366×900。分发 pagehide/pageshow 检查释放与恢复：缓存降为 0，暂停期间无绘制。该生命周期分发不冒充真机切后台测试。

## 性能与完整回归

[桌面满上限 6 只怪](full-cap.webp)，图集已预热，分别采样 8 秒。以下是同一云端 Chromium 的测量，**不是物理手机/GPU 性能结论，也不声称相对旧版本提速**。

| 桌面 1366×900、DPR 1、6 只怪、正常图集 | 60.00 | 16.70 / 17.50 | .90 / 1.50 | .10 / .10 |
| 390×844、DPR 1、6 只怪、强制 mobile+lowEnd，原 30 FPS 上限 | 30.00 | 33.30 / 33.50 | .60 / 1.40 | .10 / .20 |

- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser`：91 项通过。
