# V28.68.9 立绘驱动的2.5D首版

外观来自现有主角、灵狼立绘参考，补画为全身动作素材；不是几何人形，也不是可任意旋转的3D模型。主角有待机、突刺、挥剑三姿态；狼有站立、蓄势、奔扑三姿态。步进姿态配合场上位移、纵深排序、阴影、受击闪烁/退让、倒地和伤害数字。场景复用现有水墨山河图。动作仍是有限帧的2.5D样片，尚非完整骨骼动画。

普通野狼、山脚受伤野狼、山道壮狼接入；其他怪物保留原立绘。图片未加载或失败时保留原战斗界面。显示层不结算数值、不写存档；战斗退出、敌人清空、换敌、捕获、重置时销毁场景。补充了敌人结算后空引用的回归检查。

素材：duel-ink-poses-v28689.png（1536×1024透明PNG），六个动作的原画边界不同，绘制时按各自脚底和轮廓裁切，防止相邻姿态串入。背景仅在素材就绪时重绘缓存，Canvas DPR上限1.5，绘制目标30fps。

验证：23个游戏回归脚本、3个限流测试、7个浏览器测试。动作场景单RAF、隐藏暂停/恢复、只读状态、重复销毁、普通狼接入/其他怪物不接入、资源失败回退、敌人清空均覆盖。手机尺寸390×844和横屏844×390 Chromium检查静止、挥剑、奔扑、正式战斗攻击与退出。

性能抽样：无头Chromium，390×844、设备DPR2（画布限制1.5），已加载素材的单场景108次绘制，间隔中位33.3ms、p95 33.7ms，单次drawImage JS调用最大0.2ms。非GPU总耗时，不代表真实手机帧率，不宣称较旧版提速。Jev请求在测试中拦截。
