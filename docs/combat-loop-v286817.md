# V28.68.17 战斗循环与反馈

## 本轮落地

- 主角普通攻击造成正伤害时恢复10点灵力，受现有地域回复倍率影响、不会超过上限；技能、灵宠和持续伤害不触发。按钮标明“命中回灵”。重复点击不额外恢复；未结算刷新仍恢复完整战前快照。
- 惊雷闪与御雷套装的麻痹改成封脉：接下来两次实际行动不能使用本命术法或妖元回生，仍能普攻、重击、护体、回气。眩晕与冻结继续跳过行动，跳过的行动不消耗封脉次数。再次命中刷新至两次，不无限叠加；新战斗清除状态。技能说明及状态条同步。本地与Jev可选动作均过滤，过期的远程禁用选择重新验证后降为普攻；旧Boss路径同样禁术法。
- 附近150范围内的地图怪物名称带“境界占优 / 同境交锋 / 精英慎战 / 越境危险”；剧情挑战准备页同步提示。这是境界和精英标记评估，不是完整战力或胜率预测，低境界精英仍提示慎战。
- 2.5D角色阵亡保持原立绘直立，440ms下沉并自下而上裁去、淡出；精致画质有9枚灵光消散粒子。沿用原Canvas与动画循环，不新增资源。
- 暴击施法姿态短暂停留70ms，受击姿态增加停顿；精致画质微震幅度不超过4px、120ms消退。减少动态效果关闭位移、震动和粒子，保留淡出；轻量画质不震屏、不额外画消散粒子。伤害、奖励和存档仍由原战斗逻辑决定，不等待动画。

## 评审核对与边界

当前版本MP上限并非固定100，战斗背包可用丹药，已有护体、境界压制与整场未结算回滚。保留这些机制。本轮未加入冰系减速、火系破甲、新逃生道具、灵宠同台新动作、必定秒杀、奇遇剧情或胜利管道重构；也未改全局伤害公式、掉落与逃跑概率。宠物仍沿用既有追击反馈。避免把这些后续内容误标成已实现。
