# V28.68.24 旧装备洗练档级与数值提升

## 实际变化

洗练档级同时参考有效的 `gradeV2790` 和品质下限，取较高值。没有标记的旧装备不再全部落入一档：

- 凡品、良品、上品、灵品：至少一档。
- 精品、灵宝、宝器：至少二档。
- 仙器、神器：三档。

沿用三档体系，神器没有额外新增第四档。人物境界和强化等级不提高洗练范围。强化与洗练采用同一档级识别，所以原本误判为一档的旧仙器，其强化费用也恢复三档标准（+1为300灵石）；没有改变原有各档费用公式。

|洗练档级|攻击|防御|气血上限|灵力上限|一次费用|
|---|---|---|---|---|---|
|1|3–9|3–8|20–60|8–20|200灵石|
|2|6–18|6–16|40–120|16–40|400灵石|
|3|9–27|9–24|60–180|24–60|600灵石|

旧范围为攻击2–6、防御2–5、气血10–30、灵力5–12，再乘档级。新攻击提高50%，气血提高100%，防御与灵力提高约50%–67%。仍然随机两种不同属性，先付费生成，再选择保留或替换。保留旧词条不退洗练费。

范围表示词条最终平铺加成，不再乘品质倍率，也不会被强化+10放大。装备需穿戴才生效，气血/灵力只是提高容量，不即时回血回蓝；套装百分比、地区状态仍影响人物最终属性。

## 存档和界面

- 已有与待选词条逐条原值保留，包括低于新下限的历史值；不赠送随机补差、不强制重洗。
- 上调词条清理上限，避免新三档气血180在刷新/读档后被裁到旧90。
- 洗练页明确显示「洗练X档」和该装备实际范围、费用。
- 待选结果仍阻止再次洗练/强化，旧的过期按钮和换角色保护继续生效。

## Jev兼容与部署

游戏洗练判读请求版本升级为2。配套云函数同时接受版本1的旧上限和版本2的新上限，保留严格整数、最多两种非零属性、鉴权、域名及限流校验。转发实际数值和对应版本上限给Jev，不压缩或伪造新词条。

新游戏配旧云函数时，洗练本身与本地比较正常；Jev判读可能返回400，页面提示确认已更新本次云函数包。建议先更新云函数，再覆盖网页文件夹，原环境变量和入口 `index.main` 保留。未改认证配置，未调用付费Jev，未部署腾讯云。

发布：`xiantu-v2868.24-game-folder.zip`（顶层仍为xiantu-v2831-scroll）与 `xiantu-jev-v2868.24-cloud-function.zip`（云函数代码在ZIP根部），不可混传。

- `node scripts/analyze-forge.cjs`：180场完整种子战斗，筑基/合体/地仙初期，普通/精英/Boss野狼，旧/新规则各10种子。可穿戴剑系装备、单件价格上限为境界序号×1000；地仙武器替换为旧太虚剑检验缺失档级场景。仅一把武器配置假设洗出的满攻击+满气血，其他装备不洗练；筑基用御剑术，合体/地仙用万剑归宗，可用即放否则普攻。无灵宠、法宝、丹药，消耗品成本为0。
