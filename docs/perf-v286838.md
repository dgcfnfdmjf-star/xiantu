# V28.68.38 加载性能复测

按 `.agents/skills/xiantu-canvas-performance/SKILL.md` 重测首屏、进入世界和对战首帧。临时探针与原始数据在被忽略的 `output/playwright/`（`perf-probe.cjs`、`perf-v286838.json`、`perf-combat-before.json`、`perf-v286838-after.json`），游戏内未加入任何计时或调试钩子。

## 环境

- Chrome（`/usr/bin/google-chrome`）无头模式，390×844、DPR 3 手机模拟，触屏。云端虚拟机，无独立 GPU。
- 本地 `scripts/serve.cjs`，`Cache-Control: no-store`；每轮新建浏览器上下文（冷缓存）；拦截所有非 127.0.0.1 请求（不调用 Jev）。
- 场景：入口页 → 点击「安全启动」→ 出现片头即跳过 → `html.xiantu-v2762-ready` → 新角色进入世界（青云地图静止 3 秒采样帧间隔）→ 动画演武进入对战（野狼无图集；山贼使用 `fighters` 图集）。
- 每组 5 轮，取中位数与 P95。

## 结果

| 指标 | 改动前 | 改动后 |
| --- | ---: | ---: |
| 点击启动 → 就绪（本地） | 中位 405 ms / P95 461 ms | 中位 439 ms / P95 470 ms |
| 开始修仙 → 地图首帧（本地） | 中位 111 ms | 中位 116 ms |
| 进入对战 → 图集完成（山贼，本地） | 中位 194 ms | 中位 190 ms |
| 启动阶段图片字节 | 3,221,345 | 1,049,644 |
| 进入世界阶段字节 | 3,432,918 | 2,256,224 |
| 首次对战字节（山贼） | 2,936,809 | 722,218 |
| 首次对战字节（野狼 + 默认凝露诀特效） | 0.87 MB（含 0.82 MB 治疗帧条 PNG） | 约 0.25 MB（调色板 PNG） |
| 网站打包（`npm run package:game`） | 49,574,833（main） | 37,103,417 |
| 地图静止帧间隔 | 16.7 ms / P95 16.7 ms | 16.7 ms / P95 16.7 ms |
| JS 堆（世界 / 对战） | 4.7 / 4.6 MB | 5.6 / 6.5 MB |

本地回环下耗时不受字节数限制，前后差异在噪声范围内；真实网络下的收益按字节估算：10 Mbps 时启动图片约少 1.7 秒，非野狼对战首帧约少 1.8 秒。尝试过 CDP 网络限速，但 Playwright 请求拦截使部分请求绕过限速，限速数据不可信，未采用。

## 发现与改动

1. 启动即加载的 `duel-ink-poses-v28689.png`（2.7 MB）占启动图片 84%；进入世界时的 `monster-small-beasts-v28682.png`（1.5 MB）为该阶段最大文件；除野狼外每场动画演武都要等 2.9–3.1 MB 的 `duel-*-v286811.png` 图集加载完成才开始绘制。六张图集改为 WebP（质量 92，透明通道无损），尺寸不变；预乘后颜色平均误差约 1/255，透明通道最大误差 0。
2. 新增雷/剑/疗帧条改为 256 色调色板 PNG（2.48 MB → 0.61 MB），按家族共享纹理，只在对应技能出现时加载。
3. 打包排除 `*-preview.mp4/png/jpg/webp` 录屏（如未被引用的 `V27.84-breakthrough-preview.mp4`）；`QA/` 与 `.txt` 说明原本已排除。
4. 片头视频 `intro-v2860.mp4`（12.3 MB）使用 `preload="none"`，跳过后不再下载；本地回环下片头自动播放时会完整读取，未改动。

## 局限

无头 Chrome 与云端 CPU 不代表手机 GPU；帧间隔受 60 Hz 节拍限制，只说明静止地图无掉帧。实体手机仍需验收。
