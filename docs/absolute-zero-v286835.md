# V28.68.35 绝对零度

参考用户提供的10.03秒、1280×720、24fps视频，以霜环、中央冰晶、寒潮和冰封为视觉要点，改编为现有单体回合制战场的四阶段特效。保留角色与怪物立绘，不复制视频中的人物或群体伤害。

1. 凝霜引寒：目标脚下出现冰蓝霜纹和悬浮冰晶。
2. 霜环扩散：地面霜圈展开，低冰棱逐渐凝起。
3. 玄冰封境：真实命中后冰棱合拢，镂空区域保留目标轮廓。
4. 碎晶归寂：冰棱破碎为低伏冰晶与霜纹，淡出清场。

采用独立蓝青冰晶材质母版和8张阶段关键板，导出4+6+6+8共24帧。全程source-over合成；深青边缘与蓝色中间调适配浅色水墨背景。目标脚底锚点固定，阶段交叠互补淡入淡出，未命中不出现冰封。减少动态效果仅保留静态凝霜/命中及淡出。图片失败时使用原冰系程序特效。没有增加Canvas或独立动画循环。

技能语义不变：耗蓝70、伤害倍率4.0，目标存活时必定冻结下次行动，原寒迟效果与原回合规则保留。特效不扣血、不读写存档、不消费战斗随机数。新增专属小说出招与命中文本。

独立资源页：`absolute-zero-v286835/index.html`，支持暂停、逐帧、画质、命中开关、缩放、偏移、背景与循环。
同台试播：`battle-25d-preview.html?skill=绝对零度`，可选择不同对手。共用正式渲染器，试播不读写存档。

开发产物位于 `art/absolute-zero`。首版越界图集仅作为失败记录保存，不进入游戏。重新生成的图集、导出每帧均通过12%边距检查。`scripts/build-absolute-zero-vfx.py` 可复现导出；加 `--runtime` 同步经检查的资源和同源采样器。资源预览与实战共享同一时间采样函数。

新增QA覆盖早/正常/晚命中、未命中、脚底锚点、交叠透明度、末帧可达、图片缓存/失败回退、真实技能耗蓝/伤害/冻结/寒迟及随机数一致性、后台恢复和销毁。浏览器验收使用本地合成角色并拦截外部服务；不调用付费Jev。无需更新Jev云函数，未自动部署腾讯云。
