仙途 V28.68.109 — 青绿鎏金界面与主线入口

参考与核实
用户提供仙途6.zip、仙途7.zip和仙途5.md，包含主题CSS、图标、JS草稿和对照图。方案基于V28.68.101，当前main基于V28.68.108；当前手机任务卡已把目标与操作提前，不能照搬附件的“两屏以后才能推进”结论。
本轮采用青绿、墨色和描金边框，围绕已有手绘整景整理主要界面。未接入外部字体、UI框架或第三方图标库。

实现
- 任务、角色、行囊、装备、读档面板使用统一框线、文字和常用按钮样式；保留原有背包紧凑行与品质识别。
- HUD任务／角色／行囊／更多使用附件的本地图标；折叠HUD仍显示气血、灵力、修为的名称、数值与进度。
- 当前主线卡在任务列表DOM中置顶，包括未解锁的准备入口，视觉与阅读顺序一致；原手机操作先于插画的规则继续使用。
- 地图底部显示当前章节、目标和推进入口。故事分支只打开任务面板，不替玩家选择；未接取／锁定章节先打开原条件面板。战斗、修炼继续调用原流程和低血量确认。
- 点击时复核角色、任务对象、任务编号、实例、状态和当前步骤；同一步骤短时间连点只执行一次。战斗、结算、突破、室内、教程、主要弹窗及页面隐藏时禁用并隐藏任务条。
- 角色 → 修行与设置 → 画质设置 → 界面外观，可恢复原界面、减少界面动效；记住本机偏好，禁写存储时当次仍生效。系统减少动态效果设置也生效。角色存档不新增字段。
- 样式合入原CSS；行为合入原手机脚本，图标在HTML内。保持原40脚本顺序，无额外主题请求；三处主要资源合计增加38,627字节（未压缩）。
- 利用既有HUD/任务刷新和范围受限的DOM观察器，没有新增轮询或RAF循环；隐藏页面取消待处理刷新。

范围
本轮为主要面板主题与主线可达性。附件的头像式HUD重排、第五个宗门按钮、全系统图标替换、物品网格／纸娃娃布局属于后续设计，未声称整份多阶段方案全部完成。
建筑、室内、地图缩放、行路、经济、掉落、难度和原任务门槛保持现有语义。地点剧情仍有独立通知，不将旧地点剧情误指向27章任务系统。
