## 视觉修整

红莲最初的后段主体火星较高，最终使用已验证的低花形首帧与自身独立母稿插值，主体约 167–168×71–75px。重画的一组三格低莲发生格边界越界，明确拒用，未切片、未进入导出。小莲印约 21–22×22px。

火墙主体约 214–215×73–78px，低于设计约 80px 的参考高度少量，保留狼头、肩部和血条；不通过拉伸补高度。三昧原长尾稿被替换，独立短粗主体板约 122–123×57–66px，短尾固定跟随同一主体。全部尺寸以 720×420 实际舞台计。

原九格先验证没有跨格（2% 检查），完整单格扩边后再验证 18% 安全边界，之后才导出。所有源原图保留。导出帧可见像素中，近白面积最大 0.49%，暖红色族占比最低 94.3%。深色残烬与主焰分开设定中间调阈值，避免误把设计要求的炭色判为白化。

衔接图按实际 sampler 取重叠起点、中点和终点：蓄势→主体、主体→命中、主体/命中→余烬。双完整轮廓使用互补透明度；地面技能的命中层仅为少量碎瓣/碎焰。各非循环层末帧可达且按时退出。

## 状态合同

试播仅模拟状态输入，不写入游戏。红莲短动画结束后，同一存活目标在 `burnTurns > 0 && burnStacks > 0 && _burnHealBlockV286818` 时显示莲印。普通灼烧不显示禁疗莲印；灼烧耗尽、炎爆消耗、死亡、换目标、隐藏和退出立即清理。刷新灼烧不重启莲印相位。动图在 2000ms 明确输入一次“灼烧结束”事件，以展示清理；这不是把三次主动出招换成两秒。

火墙无持久墙体；三昧三焰合一，保持一次命中。此轮没有改变灵力、伤害、穿防或灼烧机制。
