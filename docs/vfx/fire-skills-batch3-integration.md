## 实现与机制

14 张 RGBA 图集、88 帧，以及批准的配置和采样器已原样复制到 `xiantu-v2831-scroll/fire-skills-batch3/`。21 个资源文件逐字节相同，接入前的三个旧运行文件备份在 `art/fire-skills-batch3/integration-baseline/`。可用 `scripts/promote-fire-skills-batch3-vfx.py` 重建嵌入配置，接入代码保持独立。

天火焚世从目标上方下降，落点锁定地面；赤焰龙息采用固定尺寸分段火流，Canvas 按采样器的局部裁切窗口揭示前沿；燎原火域在真实命中后爆发，在最后 60ms 余焰与持续状态交接。使用 source-over，复用已有纹理缓存与 RAF。`fireBatch3` 为独立接口，前两批 API 的定义列表不变。

火域来源仅保存在本场景内，由确认命中建立，结合真实灼烧次数、伤害、敌人存活和目标身份显示。普通灼烧、场景重新构建不能凭空生成火域。连续灼烧被其他火系刷新时保留来源；动作开始时和绘制前读取真实状态，防止灼烧归零后在同一帧被普通火系重新施加而复活旧域。既有禁疗莲印优先，其次火域，再次普通微焰，同一灼烧显示层负责。火域锁定原落点；不添加伤害、定时器或存档字段。状态清除、死亡、目标更换、重置和退出清理来源；后台暂停，恢复时先核对真实状态。

三招仍由正常 `combat('skill', 0)` 扣蓝和结算，耗蓝分别 75/58/72、倍率 4.5/3.9/4.4、灼烧 2/3/3 次主动行动。没有新增群体伤害或多段命中。核心战斗代码、数值与原有图集哈希保持不变。
