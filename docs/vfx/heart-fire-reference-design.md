## 四阶段视觉设计（待确认）

| 阶段 | 画面 | 锚点及时间约束 |
| --- | --- | --- |
| 凝心 | 掌前/胸前凝出小块赤红火芯，外缘有暗红烟丝；不绘制爱心图标 | 施法者胸前；命中前窗口前30% |
| 贯炎 | 细长赤黑火束向敌方胸口掠去，尾焰依附前端轨迹 | 移动前端，终点为目标躯干；命中前剩余70%；不拉伸主体帧代替移动 |
| 焚脉 | 胸口出现短促赤色爆点，几条分叉火纹沿躯干扩散；脚下仅少量暗灰火屑 | 真实命中事件触发；0–180ms；未命中前不出现目标烙印 |
| 余烬 | 火纹收拢为胸口一点余火，烟丝散去 | 命中后180–540ms淡出；状态持续时长仍由原战斗系统和状态提示负责 |

所有时间均为相对展示窗口，接入时跟随原hit事件，绝不延迟伤害结算迁就视频节奏。视频15秒压缩为当前战斗动作可容纳的短特效，不播放整段视频遮盖战场。

画面动词：凝聚→刺入→蔓延→收敛。玩家应读出“细束直取心脉，余炎削弱对手”。
素材配色：暗烟 #34151D，深红 #821C2D，朱红主体 #D92D36，细橙红亮芯 #FF7552；白亮区域不超过效果可见面积3%。主体不借用太阳真火或冰蝶素材改色。
尺寸：躯干火纹覆盖不超过敌人可见身高60%，保留脸部/血条；火束在战场宽度中是细长方向线，不扩展成全屏火墙。兽类取躯干中心而非照搬人类胸口。反向施法同样正确定位。
护罩碎裂：本次不作为固定视觉步骤，因为现有技能没有必定破盾机制，不能让画面宣称发生了额外机制。
