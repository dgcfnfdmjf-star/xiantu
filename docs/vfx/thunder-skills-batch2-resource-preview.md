## 制作契约

每招均从已确认的水墨电光风格独立生成全分辨率母版，再以自己的母版生成四阶段关键板。不是同一旧雷电改色。保留原始输出和被拒绝的图集，来源见 `art/thunder-skills-batch2/generation-sources.json`；运行代码不依赖图像服务。

独立原始图通过无截断边界检查后，为完整单元格扩展透明安全区域，再以18%边距检查通过后切片。紫霄落雷首张图集以及九天神雷前两张图集存在越格或雷尖碰边，已拒绝并重新生成；没有裁掉截断部分或靠运行缩放隐藏问题。

同一导出器生成清单和预览配置。每招引导4帧、主体8帧、命中6帧、消散6帧；主体在独立母版和姿态关键板之间插值，其余一次性层用透明度衰减展开，并非72张独立手绘原画。材质保留蓝紫色中间调和细青色芯，以普通source-over混合。

紫霄/九天使用60ms阶段交叉淡化、200ms命中、440ms尾段；无音使用40ms交叉淡化、120ms命中、260ms尾段。资源默认到达时间分别400/280/460ms；接入时按原命中时间重新采样，不改变结算时刻。主体尺寸固定向下运动，脚下标记固定；未命中不生成爆发和余电，低画质省略余电，减少动态省略主体。

## 查看与复现

仓库根目录启动 `python3 -m http.server 8782 --bind 127.0.0.1`，资源页为 `http://127.0.0.1:8782/art/thunder-skills-batch2/preview/`。页面使用DOM图片图层，与纯采样器共用配置，支持逐帧、慢放、命中开关、三画质、缩放、偏移及深浅背景。

构建：`python3 scripts/build-thunder-skills-batch2-vfx.py`。
清单：`node .agents/skills/creating-game-combat-vfx/scripts/validate_effect_manifest.mjs art/thunder-skills-batch2/preview/effect-manifest.json`。
采样：`node scripts/check-thunder-skills-batch2-vfx.cjs`。
证据合成：`python3 scripts/render-thunder-skills-batch2-evidence.py`。
浏览器：`node art/thunder-skills-batch2/qa/browser.cjs`。

证据位于 `art/thunder-skills-batch2/evidence/`，动画为导出资源与纯采样器合成的试播，不是实战录屏。旧资源使用其自己的帧数和尺寸切片，对比按可见边界归一化，并使用真实项目战场背景。手机尺寸验证是浏览器模拟，不等于实体手机验收。
