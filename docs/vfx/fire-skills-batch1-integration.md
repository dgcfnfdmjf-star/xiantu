# 火系首批接入验收 · 2026-10-13

已将用户确认的烈焰斩、炎爆术、焚天烈焰透明资源接入主版 V28.68.35 的开发分支 `codex/skill-vfx-expansion`。本轮为本地开发接入，未升级发布版本、提交、上传 GitHub 或部署腾讯云。

## 最终行为

- 烈焰斩以单枚固定大小的弯月火刃抵达目标，确认命中后碎焰消散；保留 18 灵力、1.8 倍伤害和 2 次主动出招灼烧。
- 炎爆术先播放普通火核命中；仅现有 `showDamageNumber` 的“灼烧引爆”通知携带实际正伤害时，为同一出招记录追加爆发时间。没有重新读取已被清零的灼烧去猜测结果，也没有新增伤害、随机判定或定时器。保留 22 灵力、2 倍伤害；出招前灼烧先结算，额外引爆只消费剩余灼烧。
- 焚天烈焰在锁定的目标脚底蓄热、命中后升起火柱，随后退为短余焰；保留 45 灵力、3 倍伤害和 3 次主动出招灼烧。轻量档省去附加碎火，仍显示命中火柱。
- 动画与资源预览共用纯采样器。持续灼烧仍由既有状态渲染负责，新短效果占用期间不叠画原状态微焰。切后台、场景重置/换目标和销毁清理沿用现有路径。
- 反向施法旋转前进主体；减少动态模式取消平移，旧 DOM 战场仍显示静态命中/引爆，并不额外开动画循环。

资源：`xiantu-v2831-scroll/fire-skills-batch1/`。试剑坪：`battle-25d-preview.html?skill=烈焰斩`，可切换另外两招；新增“对手带灼烧”选项，供炎爆术追加事件试播。该页使用正式 Canvas 渲染与动作路径，不影响玩家存档。

## 性能测量及边界

同一台云端无头 Chromium，390×844、DPR 2；独立 720×420 Canvas、每招 240 次同步绘制，精致档、图集预热后。旧版 p95：烈焰斩 0.9ms、炎爆术 0.8ms、火柱 1.0ms；新版分别约 0.2/0.1/0.1ms。60 次 RAF 间隔中位均约 16.7ms，p95 由 16.8ms 到 16.7ms。低于计时分辨率的中位数记录为 0，并不表示零开销。这些是 CPU 提交耗时与空闲试剑坪 RAF，不代表 GPU 或实体手机 FPS；没有据此加入额外优化。

实际火柱峰值会短暂遮挡狼身部分，头部和血条仍可识别。尚未做实体手机验收；发布前可继续核对大体型与飞行敌人的遮挡。此次不生成发布包、不变更 40 模块加载顺序，也无需更新 Jev。
