每招有自己的完整材质母版及六格关键板，按蓝紫水墨电光风格独立生成；不是把同一旧雷电改色。每套导出引导 4 帧、主体 8 帧、命中 6 帧、消散 6 帧和事件 6 帧，共 **20 张 RGBA 帧条、120 帧，PNG 合计 2,096,395 字节**。主体由两张已绘制关键板插值，不宣称 120 张独立手绘原画。

闪电链按端点距离一次性确定等比尺寸，播放过程中不拉伸主体。雷笼、附体和雷云采用 8 帧循环；停止时与消散层交叉淡化。减少动态保留静态状态轮廓，轻量模式省略消散装饰。反噬只由输入事件触发，命中闪光收为小范围，避免误读为敌人也获得雷铠。

## 制作检查

- 第一版闪电链图集的雷尖侵犯相邻单元边界，已拒绝并重新生成，原图保留为 `keyplates-rejected.png`。
- 所有原始单元先通过 2% 边界检查确认无截断，再扩展完整单元的透明区域，通过 18% 安全边距检查后切片。没有裁断雷尖、降低透明度或修改游戏缩放来掩盖边界问题。
- 按 alpha > 16 的可见像素统计：白色最高占比依次为 3.83%、0.69%、0.93%、1.74%；蓝紫材质最低占比依次为 95.76%、99.19%、98.79%、97.39%。审计从当前源图和导出帧重新计算。
- 已检查引导/主体、主体/命中、主体/退出的过渡合成。持续主体在命中时保留，其冲击层只增加接触信息；退出交叉淡化不保留第二个完整轮廓。
- 新旧材质对照按可见边界归一化，旧图按旧清单切片。实际预览另按施法者、目标脚下和目标上空定位，血条与人物脸部可辨。

生成来源见 `art/thunder-skills-batch3/generation-sources.json`；透明源图、独立母版、安全边界图和重新计算的审计均保存在该目录。

## 预览与复现

仓库根目录运行 `python3 -m http.server 8782 --bind 127.0.0.1`，打开 `http://127.0.0.1:8782/art/thunder-skills-batch3/preview/`。

页面支持四招切换、播放/暂停、逐帧、慢放、帧率、缩放、偏移、深浅背景、方向、命中开关、模拟状态期限、事件开关和离场清除。普通九霄雷云可关闭「模拟持续状态」检查一次性收尾。所有事件均是预览模拟，不是实战伤害或状态判定。

```sh
python3 scripts/build-thunder-skills-batch3-vfx.py
node .agents/skills/creating-game-combat-vfx/scripts/validate_effect_manifest.mjs art/thunder-skills-batch3/preview/effect-manifest.json
node scripts/check-thunder-skills-batch3-vfx.cjs
python3 scripts/render-thunder-skills-batch3-evidence.py
node art/thunder-skills-batch3/qa/browser.cjs
```

`effect-manifest.json` 和通用预览清单由同一导出器生成；自带预览另外消费纯采样器，才能完整检查状态期限、雷云上下分层和事件时间。动画、分镜与过渡对照位于 `art/thunder-skills-batch3/evidence/`，`provenance.json` 记录生成命令和输入哈希。视频由同源 PNG 和采样器合成，**不是游戏实战录屏**。

## 资源预览阶段验证结果与接入边界

- 4 个效果清单通过；504,000 次纯采样通过，覆盖命中/未命中、早晚命中、双向、三种画质、有无持续状态、有限/无限持续、最后一次雷伤、最后一次反噬、提前结束、销毁和输入不变性。
- 末次反噬在雷铠到期后完成自己的短命中动画，不恢复雷铠；同事件 ID 不重复播放；动画不读取随机数或修改战斗数据。
- Chromium 151、无头、DPR 1 的资源预览检查通过；390×844、844×390、1366×900 无横向溢出，缺失单张素材只阻断对应技能，未出现页面错误。仅为浏览器模拟，不代表实体手机验收。
- `npm test`：56 组游戏回归脚本及限流测试通过；现有浏览器回归 7 项通过。这些结果保护当前游戏，不代表新资源已接入实战。
- 游戏目录与开始时的 `runtime-baseline.json` 逐文件核对；本阶段不更改伤害、灵力、控制、存档或 Jev。
