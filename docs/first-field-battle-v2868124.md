# V28.68.124 新手首场野战

在 `9bd84d7` 上用 18 个新角色记录了南域的第一场普通游荡怪战斗。16 场战败，2 场脱战。走完引路并穿上布衣、木剑的 9 个角色也都未取胜。因此，凡人初期从引路进入南域野外时，首场普通遭遇先给玩家一次查看双方气血和暂避整备的机会。小样本缺少用药、先突破和购置装备等打法，也没有目标胜率，沿用原有敌人属性、技能消耗、伤害和奖励。

## 实测条件

- Chromium 151.0.7922.173，1280×800，本机静态服务。每场使用独立临时档，通过序章，保留游戏原本的随机数、回合计时、敌方行动和结算。阻断外部服务。
- 跳引路组领取系统补发的基础物资，布衣留在背包。完整引路组实际击败演武傀儡、穿戴布衣、完成山脚试手、穿上木剑、配置御剑术、战胜山道壮狼并收好来信。表中只计随后首场普通野战，开战前保留上一场自然剩余气血和灵力。
- 两组都为凡人初期，无灵宠。沿游戏的地图寻路实际走到自然生成的南域普通怪身边。演武、引导狼、任务、精英、首领和天劫均排除。双方未被传送、补血、提级或注入装备，手动战斗没有用药。
- 每组交替测三种策略，各三场。简略战报手动点普攻，或优先点可用的御剑术，缺灵力时普攻。默认演武使用游戏的 1 倍自动选招。
- “回合”计实际接受的玩家行动，普攻、攻击招式和治疗各占一回合。从战斗面板出现开始，直到引擎发出结算事件，计入正常动画、等待对手和操作时间。计时排除寻找怪物、阅读整备提示、奖励展示和返回地图。战败或脱战照样记录。

## 复测

仓库根目录执行 `npm ci` 和 `npm start`，在另一个终端运行以下命令。系统 Chromium 的安装位置可通过环境变量指定，每条命令会为相应路线生成九份战斗记录。完整逐回合操作和资源输出到 `output/balance/first-battles-{skipped,guided}.json`。精英先接触或三十秒内未遇到普通怪会写入排除原因，并重新建档；每个样本至多尝试五次。随机生成的对手、选择和实时时间会在复测时有所变化。

```sh
export PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium
node scripts/measure-first-battle.cjs http://127.0.0.1:8765 skipped
node scripts/measure-first-battle.cjs http://127.0.0.1:8765 guided
```

修改后的采样会在提示出现时点击“仍要出战”，继续用同一计时口径记录。选择“暂且避开”会留在地图，并得到原有的八秒避让时间。提示使用角色已有的引路阅读记录去重。初期之后、已有普通击杀、精英和其他地域沿用原有接触逻辑。低于半血时仍可先去补给。
