开场行为
- 默认首次播放。主动跳过、进入或自然结束才记录已看；加载失败、禁止自动播放、慢网与中断不记录。
- 保留原 xiantu_skip_intro_v2898 选择。新已看标记 xiantu_intro_seen_v286891 与游戏存档无关，不重置玩家数据。
- Save-Data 或 prefers-reduced-motion 自动跳过；“观看开场”可在开始前或加载期间主动重看。
- 就绪后隐藏重看入口并显示视频上的“进入仙途”。加载器等待当前播放任务，防止重看时等待旧 Promise。
- 竖屏窄窗口（<=640 CSS px）或 2G/3G 优先360p，其他优先原960x540。另一个源为错误回退。
- 每个源3.5秒未开始、播放后卡顿8秒、整段45秒兜底均安全返回加载页。加载文件继续进行。
- 默认静音、内联播放；完整画面 contain，不拉伸。播放退出250ms淡出，减少动态效果直接退出。
- 所有退出移除媒体 src、监听和定时器；旧源事件/Promise拒绝不能终止后续源；页面离开清理渐隐和等待任务。

这不是网络已接收字节的百分比：大文件未完成时进度会停留，6秒无该资源完成即显示慢网提示。

第一次失败自动重试，再失败显示手动继续，已完成模块不重跑。慢网未完成请求不超时重插、不刷新存档。
提示定时器在就绪、致命错误和pagehide清理。
