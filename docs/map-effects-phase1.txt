地图／事件特效第一阶段（待发布）

范围
用户选择先做可开关的地图／事件特效，室内保持手绘。本轮不接入 3D 炼丹房，不改变移动、探索、战斗、炼丹、突破概率或收益，不删除高清开场。
入口：角色 → 画质设置 → 地图 / 事件特效。关、低、高、自动仅保存在本机 localStorage，不新增玩家存档字段。自动档手机优先低档；系统减少动态效果优先关闭。
炼丹房／药庐附近增加烟火微光，大殿、藏经地点、军令台增加地面阵纹；高档增加环境微光与移动脚下光点。地点效果检查真实探索记录和可见范围，不揭开迷雾。
实际炼丹成功后播放最长 1 秒光点，实际突破动画期间播放最长 1.5 秒光点与阵纹。沿用原结算与动画，不新增点击阻挡。

加载与资源
原 40 个必需脚本顺序不变；宿主在游戏内按需加载 xiantu-v2868104-map-fx.js，后者按需加载本地 vendor/three-r128.min.js。关档及减少动态效果下不请求这两个文件，组件失败不阻止游戏。
Three 来源：npm three@0.128.0 的 build/three.min.js，逐字节核对官方 r128 build/three.min.js 一致；未修改，603445 字节。
SHA256：9274bbcec8d96168626c732b5d31c775aa8cfb7eaa0599bec0c175908a2c1ce2
许可证：vendor/THREE-LICENSE.txt（MIT），打包显式保留。运行时不依赖外部 CDN。
粒子与阵纹纹理由 Canvas 一次生成，预分配粒子池；粒子动画使用独立种子，不改游戏随机算法。第三方库初始化仍有其内部对象标识生成，不宣称整个库零调用 Math.random。

渲染与清理
单个 WebGL renderer，复用 world3dCanvas，透明、不抗锯齿、无灯光／阴影／后处理；高档 DPR 上限 1.5，低档 1。地图只挂现有帧循环，无额外地图 RAF。
低档单个烟火 100 粒子，高档 220；最多两处烟火，加高档环境 120 与脚下 48，地图最多 608 粒子。事件最多 300 粒子；轻量回退每组最多 40。
使用原始帧时间观察持续掉帧，预热后连续两次 2 秒窗口低于 24 FPS 或慢帧比例超过 25%，按高→低→轻量→关降级；不会自行反复升档，手动设置可重置。
无 WebGL、加载失败、上下文丢失时释放 GPU 资源并回退轻量 2D，当前会话不反复创建 WebGL 上下文。菜单、室内、战斗、切后台暂停；换玩家、重置、退出事件面板取消短时动画和过期加载回调。

兼容核实
现有启动层已在所有模块之前补齐 Array.at 与 Object.hasOwn。运行代码未使用 findLast 或 structuredClone，本轮不添加会丢失类型语义的 JSON structuredClone 全局替代。
Chromium 测试主动移除上述 API 后可启动 40 个模块、进入游戏、打开任务并保存；移除 at／hasOwn／findLast／structuredClone 后也可加载额外特效。此项是 API 缺失模拟，不等同于真实旧 iPhone 验证。

性能实测
本机 headless Chromium，390×844、模拟设备 DPR 2，游戏画布 DPR 1，手机 30 FPS 上限；西域炼丹房门前，11 地点、4 野怪，同场景预热 6 秒后采样 6 秒。阻断外部网络，临时角色；原始记录位于忽略目录 output/playwright/fx104-*。
低档开启：187 样本，drawFlatWorld 中位 0.9 ms／p95 1.8 ms，特效宿主与提交中位 0.2 ms／p95 0.3 ms，实际 1 次 draw call、100 粒子；帧间隔中位 33.3 ms／p95 33.4 ms。
关闭对照：drawFlatWorld 中位 0.9 ms／p95 2.1 ms，宿主门控 p95 0.1 ms；帧间隔中位 33.3 ms／p95 33.4 ms。关闭时没有请求额外模块与 Three。
上述是 JavaScript 时间及帧间隔，不能代表 GPU 耗时或实体旧手机性能，也不能据此承诺所有设备维持 30 FPS。截图期间有长帧，未用包含截图的平均间隔宣传帧率提升。
