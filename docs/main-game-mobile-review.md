# 主游戏首次游玩与双指操作复核

基线为 `origin/main@799076769624e459428cb3657e8361a8e810b5d7`，版本为 28.68.124。用云端 Chromium 151 在本地游戏上创建临时角色，外部请求全部拦截。五项检查来自 [Gemini 源码评审](https://gemini.google.com/app/4530937c7bb76c0a)。

## 首次游玩

390×844 触屏模拟，勾选跳过片头，从打开游戏页计时。3.9 秒看到序章的“握紧木牌，抬头看向老者”，继续点“踏上仙途”和“开始引路”，7.9 秒出现“轻点地面或拖动摇杆，移动一小段”与摇杆高亮。将摇杆拖向出生点右下方的四方驿道，进入外圈后点“交互”和“开始演武”，11.3 秒看到“点击【普攻】完成第一击”。连续点普攻打赢演武傀儡，15.4 秒看到“穿戴所得”。全程通过游戏控件推进。另用空白配置从网站首页进入，保留默认片头。2.9 秒时片中已有“进入仙途”按钮，等待片头完整结束则在 32.6 秒看到序章选项、36.4 秒看到摇杆提示。时间来自自动操作，真人阅读序章需要另计。

## 摇杆与战斗

地图上摇杆配套的按钮是“交互”。进入手动战斗后，技能出现在战斗行动区。用 Chromium 的 CDP 输入保留第一根手指，并分别抬起第二根手指，主线可重复出现两个漏点。

| 操作 | 基线 | 本次修改后 |
| --- | --- | --- |
| 在驿道外圈按住摇杆，另一指轻点“交互” | 收到第二根手指的按下与抬起，按钮点击 0 次 | 点击 1 次，打开“三界行路” |
| 按住摇杆进入野狼遭遇，另一指点“御剑术” | 灵力停在 100 | 灵力从 100 降至 90 |

修改只在一个触点始于摇杆、另一个触点始于地图交互键或战斗按钮时接管该次轻点。沿用按钮原有的点击处理。第二指拖出再拖回、操作取消或控件被替换时均会放弃本次点击。摇杆的移动计算沿用原实现。入口页以仓库脚本刷新加载进度权重，40 个脚本权重中只有摇杆一项从 3953 变为 5852 字节。主游戏 ZIP 和对应校验同步至本次改动。

松手与系统取消均在对应指针事件中清除方向，随后连续 6 次 RAF 角色坐标保持一致。标题页双指缩放实测从 1 到 2.52 倍，横屏序章的文字区可用手指从 0 滚到 101 CSS 像素。用受控 RAF 时间戳复核 PR #96 的 `movePlayer`，60、120、144 Hz 各运行 1 秒均移动 300 CSS 像素。iPhone Safari、微信内置浏览器及物理高刷屏仍待真机验收。

## 地图切换

临时角色解锁北域，站在各图出生点。南域 2030×1450、北域 2320×1740，从南域出发交替切换 12 次。观察实际的 `travelToWorldMap`、`drawFlatWorld`、整景图缓存和离屏地形画布。主地图调用 Canvas 2D。炼丹舞台单独使用 Three.js/WebGL。

云端 Chromium 无头，390×844、设备 DPR 2、自动画质，实际地图 DPR 1。每次等整景图和静态地形就绪后收集 32 帧。下表汇总切换后的 384 帧，绘制耗时为 JavaScript 调用耗时，帧间隔为相邻实际绘制的开始时间差。

| 地图 | 帧数 | 绘制中位数 / P95 | 帧间隔中位数 / P95 |
| --- | ---: | ---: | ---: |
| 南域 | 192 | 0.8 / 1.5 ms | 33.3 / 37.9 ms |
| 北域 | 192 | 0.9 / 1.7 ms | 33.3 / 42.8 ms |

两图预热后整景缓存 2 张，请求合计 2 次。页面资源请求停在 57 次，DOM 中有 10 个 canvas。每次切换，上一张地形画布缩至 1×1。首轮北域至末轮南域，强制 GC 后的 JS 堆从 5.38 到 5.97 MiB。此次采样未见地图资源或画布逐次叠加。短时 JS 堆变化不足以判定泄漏。另开空白上下文延长到 36 次切换，整景请求仍为 2 次，最后 12 次 GC 后 JS 堆处于 6.26–6.30 MiB。该轮南、北域各采 576 帧，绘制 P95 分别为 1.4 与 1.7 ms。未测 GPU 内存。

## 存档转移

浏览器上下文 A 的临时角色“云游测试”从存档管理下载 JSON。上下文 B 的临时角色“留守测试”先导入改过灵石、保留原校验码的文件，收到校验码不符提示，主档、滚动备份和替换前记录均逐字节保持原样。再经文件选择框导入 A 的原文件、点击确认，目标主档的完整内容与导出载荷相等。滚动备份保留 B 的原主档，“恢复替换前记录”可找回 B 的角色与 9 灵石。A 仍保有原角色与 502 灵石。另有现成用例覆盖截断、取消、旧档迁移和重载。

## 炼丹掉帧与重播

当前舞台脚本的 Git blob 为 `87da90411f50eee845691b5644f43ed25761a5fd`，与 [PR #97 核对过的原样附件](https://github.com/dgcfnfdmjf-star/xiantu/pull/97) 一致。本次保留该脚本。

用实际 WebGL 舞台播放两味药材、三枚成丹的临时展示结果。在舞台 `play` 入口控制 RAF 时间戳，读取烟尾颜色缓冲区。每 50 ms 推进一次，1.5 秒时有色点为 0。直接从 0.5 跳至 1.5 秒时有色点保持 16，到 5.2 秒片尾仍为 16。重播的第 0 帧清为 0，0.5 秒时正常生成 16 点。原因是跳过了写零的帧，1.4 秒后的分支只隐藏药材精灵。后续如允许修改附件，可在越过窗口时隐藏整组烟尾，并在下次播放时恢复可见性。

另用独立临时 Chromium 配置开炉后切换标签页，通过真实 `visibilitychange` 确认隐藏时舞台 canvas 从 1 变 0。返回后创建一张新画布并显示“炉火待启”。该次消耗 2 灵草、得到 1 枚小还丹，切回没有重复结算。

## 复现

在仓库根目录安装锁定依赖。在有系统 Chromium 的环境可指定其路径。浏览器回归自带临时服务器和临时存储。

```sh
npm ci
export PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium
npx playwright test joystick-multitouch save-transfer tutorial-pacing map-frame-timing alchemy-show
```

要重采地图与炼丹数值，先运行 `npm start`，再在另一终端执行下列命令。脚本自动创建独立浏览器上下文，输出包含每轮场景、画布、资源、JS 堆、绘制耗时、帧间隔和烟尾计数的 JSON。命令末尾可加 `36` 重跑延长采样。

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium node scripts/probe-map-alchemy.cjs
```
