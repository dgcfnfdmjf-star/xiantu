# V28.68.41 会战斩将与弟子点兵

本轮接入现有正魔大战、2.5D斗法、军功补给和弟子履历。完成建议落地顺序的前两步。情报迷雾、占领分坛、盟宗重建及新军功商品留待后续，并未以文案代替实装。

## 进入方式

宗门大殿 → 山门军务 / 正魔大战 → 战前筹备 → 确认出征。在大地图军令台点「参战」进入三阶段军务面板。各阶段先选统领（可省略）和战术，再选亲自交锋或统领联军。第三阶段出现「主将阵前单挑」。战后三阶段完成，点「结算本场战役」领取一次奖励。

## 出征境界奖励

以出征时的境界锁定倍率。中途突破、换装、刷新不会改变它。灵石和修为放大，贡献、军功、斩敌数量及冷却保持原规则。没有直接套用早期境界小于1的实力系数，以免低境界奖励反而缩水。

## 主将限时战

- 仅新版第三阶段改变规则；前两阶段仍可亲自交锋。
- 消耗1战备，最多8次玩家行动（包括防守、治疗和被威压阻止的行动）。最后一次行动的正常伤害、灵宠和同伴支援可以完成击杀；到敌方行动入口检查是否到时，不依赖现实秒数。
- 击败敌将：完成阶段，最终联军战力额外×1.30，并按原规则记一次亲自胜利。
- 到时敌将剩余气血≤30%：以重创完成阶段，最终战力×1.15；不计亲自击杀军功。
- 到时未重创或自身负伤：士气−10，该次斩将机会消耗；可以继续「统领联军」，没有额外扣钱或永久卡关。
- 一场战役只有一次最终斩将机会。未结算交锋刷新后从已付战备的开战存档续行，不再次扣战备；敌方和计数重置到交锋起点。
- 加成参与真实战力比和胜果判断，不强制把任何劣势变成大胜。敌方数值、角色技能和装备公式沿用现有战斗。

## 三阶段统领

每阶段可委任一位不同的空闲弟子，最多三位。当前阶段尚未出战可撤换；完成阶段后随军至战役结束。不会同时派遣、培养或接受古洞后续任务，已有派遣也不能改派随军。

- 果敢 + 集中突击：阶段额外优势+1。
- 谨慎 + 稳守反击：完成该阶段后，整场基础战力修正最低100%；再乘斩将加成。
- 仁厚完成阶段：战败灵石损失减少50%，战后繁荣恢复3；有「济危同门」称号则减少75%、恢复6。多位仁厚取最高效果，不叠乘。
- 每次完成阶段记录「随军参战」；阶段取胜再记「战场取胜」。累计三次阶段取胜获纪念称号「破魔先锋」。履历有界，旧记录保留。

战力仍含原弟子等级贡献；本轮新增的是指挥作用，不重复累加基础战力。撤军、结算自动解除随军占用。

## 存档与结算

已有战役不强制切到新版规则：原奖励倍率×1，第三阶段无新增限时。新版出征保存规则标记、境界和统领快照。存档归一化保留合法统领，过滤重复/错误标记。

出征、委任、战术、指挥推进、整备、撤军、会战结算、军功兑换使用同步保存事务；失败时恢复本次变动。交锋失败保存时恢复已付战备的开战快照，允许重新完成。奖励、军功和战史同次写入；历史战报只读，重复结算无收益。沿用本地主档与备份机制，不宣称本地存储能保证浏览器数据被删除后仍恢复。
