仙途 V28.68.66 · 山河灵动

入口与范围
小地图旁「探索 → 灵动」在高、低、关之间循环；手机默认低，桌面默认高。
按地区及游戏日确定天气，季节按游戏历法；昼夜色调按玩家设备本地时间。
显示飘落物、雨丝、鸟群、蝶与萤光、旗幡、炊烟、阵光、脚步尘土/水波、行走起伏。
高档还显示流星、闲立仙鹤、遇近逃走的灵狐；没有奖励、碰撞或存档条目。
「关」关闭本轮新增环境动效和前瞻，保留原有地图表现、镜头平滑及地标放大。
系统减少动态效果会停止本轮粒子、行走起伏、前瞻，保留静态色调与建筑点缀。

适配附件时修复
附件要求增加六个独立加载文件，与当前实际结构不符；合入已有 duel 模块，
保留 40 脚本加载顺序及已有层次表现包装。core 使用明确调用点，不再包装地图布局。
独立伪随机发生器驱动环境，不调用 Math.random，不影响战斗/掉落的随机序列。
画质内存缓存避免每帧读存储，保存偏好失败仍可在当前页面生效，支持跨页签同步。
关闭、降档、换图、传送、切换角色、后台暂停都清理粒子/彩蛋/镜头临时状态。
新增表现使用可暂停的时间累计，沿用唯一地图循环；无新增轮询、RAF 或常驻计时器。
修复逃跑灵狐一边淡出一边增加透明度、导致迟迟不消失的问题。
建筑装饰随物体绘制次序绘制，避免最后覆盖前方角色；交互圈不随新增地标比例放大。
地标仅放大绘制，不改 POI 半径、坐标、碰撞、寻路、存档或奖励。
镜头保留未取整位置，绘制时按设备像素对齐；点击转换使用同一绘制镜头并除以 DPR。
桌面画布清晰度最高 1.5，低内存/手机保持 1，持续低帧率降到 1；不改全局 lowEnd。
同时适配实际生效的 mobile-dedicated 视口覆盖层，桌面 DPR 不再被后加载代码锁回 1。
降级发生在绘制开始前，避免一帧绘制中途改变画布大小造成空白。

验证
改编附件测试，加入随机数隔离、存储失败、关闭/降档清理、角色/后台重置、
DPR 点击坐标、逃跑淡出等断言。所有地区、高低档、原有层次开关均覆盖。
游戏回归 94 个脚本；安全/限流/包装工具 16 个测试；打包 4 个测试。
现有真实浏览器回归 7 项。手机画质按钮实际点击循环；360/390 与横屏布局沿用回归。
实际查看南域雨夜、北域飞雪、魔域灰烬、默认落花及横屏截图。
只使用临时角色，屏蔽外网与 Jev；没有使用玩家存档或发起付费模型调用。

性能记录（不是实体 iPhone 验证）
系统 Chromium headless，iPhone UA/触摸模拟，390×844，设备 DPR 2，地图 DPR 1，
南域暖资源，CPU 4 倍降速，每档采样约 2.5 秒，原有地图层次效果开启：
关：75 帧，drawFlatWorld JS 中位 3.3ms / P95 7.0ms；帧间隔中位 33.3ms / P95 35.1ms。
低：75 帧，绘制 JS 中位 3.4ms / P95 7.9ms；帧间隔中位 33.3ms / P95 36.5ms。
高：58 帧，绘制 JS 中位 3.6ms / P95 28.4ms；帧间隔中位 33.7ms / P95 100.3ms。
高档在模拟环境有明显长帧，手机保留默认低档，用户可关闭。JS 时间不等于 GPU 时间。
桌面窄窗口基线与后测有明显共享主机抖动，不用于声称速度提升；附件性能数字未采信。
菜单打开与调用后台暂停后的观测窗口均 0 次地图绘制；连续恢复 5 次只申请 1 次地图 RAF。
减少动态效果后粒子总数为 0。无实体手机续航结论。
桌面 DPR 2 / 1366×768：画布实际 DPR 1.5、2049×1152，真实 pointerdown 的目标误差为 0。
模拟连续三次低帧率读数后回到 DPR 1、1366×768，镜头保持有限数值。
