# V28.68.11 群妖动作战斗

以已有 monster-map-v2853.webp 和小兽立绘为参考，补画四张 1024×1536 的透明动作图集，新增 22 类、共 44 个独立绘制的准备/攻击姿态。待机呼吸与蓄势共用准备帧；受击退让、离地阴影和倒地由 Canvas 表现层组合。属于有限帧 2.5D，不是完整三维或骨骼动画。

| 图集 | 对应种类（每种两姿态） |
| --- | --- |
| duel-beasts-v286811.png | 冰霜狼、九尾狐、虎、猿、蛇、蛛 |
| duel-wings-v286811.png | 鹰、凤凰、龙、兔、龟、蝙蝠 |
| duel-fighters-v286811.png | 树精、石傀儡、山贼、邪修、魔将、幽鬼 |
| duel-bosses-v286811.png | 仙卫、战魂、迷雾领主、血魔老祖 |

连同原野狼共 23 类。继续使用共享种族映射，普通和精英名称采用相应种族动作，并补上“秘境之主”到仙卫的映射。夜无疆、天劫和没有已知种族映射的剧情角色保留原演出，不用其他种族素材替代。

四足扑击、野兔跃击、飞禽俯冲、虫蛇突袭、重型敌人的短距离重击、人形挥斩及远程施法分别配置位移、离地高度、尺寸与特效。大型角色扩大比例、下移站位，避免遮挡血条。动作名称仅用于表现，不改变技能结算或敌人策略。

图集按遇到的种族组懒加载并共用缓存；加载失败、尺寸异常或 10 秒未就绪时保留原战斗表现。没有新增动画定时器，沿用单 RAF、30fps、DPR 1.5 上限和后台暂停。读取源图 alpha 分析得到不规则裁切边界，元数据内嵌在现有 duel 脚本；图像像素未通过脚本修改。裁切避免长尾、翅膀和兵器串入相邻姿态。

battle-25d-preview.html 增加 23 种对手选择，可查看双方攻击、治疗及击倒。切换对手会销毁旧场景、取消演示伤害回调并恢复演示状态。预览不读写游戏存档。
