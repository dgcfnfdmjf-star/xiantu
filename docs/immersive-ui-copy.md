# 入口与界面文案优化

参考用户提供的 V28.68.38 界面建议，在当前 V28.68.41 上修改对应入口和文案，未整份覆盖旧代码，也未执行批量移动文档的命令。

## 调整

- 首页与旧版入口突出「踏入仙途」。首页将试剑坪、技能预览、怪物图鉴与天机连接检测收进默认折叠的「演武试剑与天机检测」，保留当前目标地址和缓存参数。
- 删除启动时的测试角标，保留原脚本及版本标记。角色的「修行与设置」中仍可查看「版本信息」。加载顺序、版本校验和加载失败提示继续生效。
- 「材料工坊」更名「百艺工坊」，改写炼丹与灵材说明，删除面向开发迁移的提示。配方、消耗、强化及材料迁移逻辑未改动。
- 常用 Jev 入口改为「天机」，自动选招入口同步更名。用量面板注明由 Jev 提供服务，保留计费、用量与配置说明。

入口支持键盘展开、可见焦点和至少 44px 的点击区域。本次不增加依赖或图片资源，不调整玩法数值与存档格式，无需更新 Jev 云函数；未进行发布版本升级。
