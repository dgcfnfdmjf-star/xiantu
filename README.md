## 发布云函数与限流配置

```sh
npm run package:cloud
```

使用 `dist/xiantu-jev-cloud-function.zip`，入口 `index.main`。根目录旧的 `xiantu-jev-cloud-function-v2850.zip` 是交接历史附件，**不要用于本次更新**；新包包含 `rate-limit.js`。无需第三方运行依赖。

原有 `JEV_API_KEY`、`JEV_ACCESS_TOKEN`、`JEV_ALLOWED_ORIGINS`、`JEV_PUBLIC_PLAY` 继续使用，不要将密钥写入仓库。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `JEV_MAX_REQUESTS_PER_MINUTE` | 6 | 每个固定 60 秒窗口内最多发起的付费请求数；失败调用也占预算 |
| `JEV_MAX_REQUESTS_PER_HOUR` | 60 | 付费请求小时预算 |
| `JEV_MAX_REQUESTS_PER_DAY` | 300 | 付费请求24小时预算 |
| `JEV_MAX_SESSIONS_PER_HOUR` | 300 | 公共票据小时签发预算 |
| `JEV_MAX_SESSIONS_PER_DAY` | 3000 | 公共票据24小时签发预算 |
| `JEV_MAX_CONCURRENT` | 2 | 同时付费请求上限 |
| `JEV_MAX_SESSIONS_PER_MINUTE` | 30 | 全部公共票据签发预算；每个来源 IP 最多 5 次/分钟 |
| `JEV_REQUIRE_SHARED_LIMITER` | false | 设为 `true` 时强制要求共享限流，缺配置或故障返回 503，不调用付费提供方 |
| `JEV_RATE_LIMIT_URL` | 无 | Redis REST API 的 HTTPS 地址，支持 JSON 命令数组与 EVAL；例如兼容 Upstash REST 协议的服务 |
| `JEV_RATE_LIMIT_TOKEN` | 无 | Redis REST 服务令牌，在云函数安全环境变量中设置 |

同一公共票据的非缓存请求保持 10 秒冷却；独立票据可以同时使用。私人访问口令仍代表一个共享 owner 身份。成功缓存结果不产生费用，也不占新的请求预算。

**多人、多实例生产部署必须启用共享限流。** 所有同一部署的实例指向同一专用 Redis 库，并设置 `JEV_REQUIRE_SHARED_LIMITER=true`。Lua 原子处理会话冷却、总预算和带过期时间的并发租约；进程崩溃的租约最多保留 30 秒。不同部署使用独立库，避免共享键空间影响预算。代理须保留可信网关提供的 `event.requestContext.sourceIp`；不能用用户可修改的 `X-Forwarded-For` 替代，来源缺失时保守合并为 unknown。

未配置 Redis 时保留兼容的**单实例内存限流**，计数在冷启动时重置，不是多实例总额度。正式上线前还应在腾讯云/API 提供方设置账户级额度和费用告警；任何每分钟限流都不等于月度费用上限。公开签发的票据不是可靠的用户账号身份，网关还应配置 IP 滥用防护。

本次仅实现并本地验证代码，未修改线上腾讯云、Redis 或费用配置，也未执行部署。
