# 仙途游戏数值分析

本项目定制技能，不是下载的官方插件。适用于伤害、装备、怪物、突破、奖励、商店和资源循环分析。先阅读根目录 AGENTS.md；涉及运行代码修改时同时使用 xiantu-web-game。

1. 沿 game-v2762.html 的实际加载顺序读取公式及后续覆盖。区分基础数值、装备、阶段倍率、境界压制、暴击、技能和怪物类型。为结论标注函数和文件来源。
2. 先运行 `node scripts/analyze-balance.cjs`。临时数据只写入忽略目录 output/balance；使用模拟角色和隔离存储，禁止读取玩家真实存档或访问付费 Jev。
3. 战斗分析分层：单次伤害探针、完整回合模拟、真实浏览器验证。固定随机值仅用于公式比较；不得由单击伤害推断胜率。完整战斗模拟应固定并记录随机种子、样本数、策略、技能冷却、耗蓝、治疗、宠物、状态和先手；报告胜率区间、回合数分位数、资源消耗。
4. 覆盖各境界与合法阶段、裸装/普通可得装备/理想装备、普通/精英/Boss/渡劫和跨境界挑战。理想装备不代表玩家实际可获得；默认角色直接调整境界不代表自然养成角色。
5. 成长分析核对突破需求、实际修为来源、失败代价、材料门槛及瓶颈。收益换算必须注明游戏日、现实分钟或战斗次数；不可假定操作耗时。概率掉落同时说明期望值与长尾。
6. 经济分析列出可重复与一次性收入、购买/强化/炼丹等支出、冷却、等级限制和买卖套利。迁移补差不能重复计为新收入。
7. 输出可复现命令、输入条件、结果表、证据边界和优先级。未规定目标节奏时先给基线与待验证风险，不擅自设定目标胜率或更改生产数值。
8. 真正调参时先保存前后对比，检查存档兼容与奖励幂等；运行相关回归及浏览器测试，再按现有发布流程打包。技能与分析报告变更无需重传游戏。
